# NeuralDeck

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
![Platform](https://img.shields.io/badge/platform-win%20%7C%20mac%20%7C%20linux-lightgrey)
![Status](https://img.shields.io/badge/status-stable-green)

> Your invisible AI command center. Access ChatGPT, Gemini, Claude, DeepSeek, and local models from a single floating interface built with C# Avalonia.

## Características

- Acceso Instantaneo: Vive en la bandeja del sistema. Un clic y aparece
- Multi-AI Hub: ChatGPT, Gemini, Claude, DeepSeek, Perplexity
- Modo Stealth: Privacidad, limpieza de cache, bloqueo de trackers
- Cross-Platform: Windows, macOS, Linux

## Instalacion

```bash
git clone https://github.com/murapadev/NeuralDeck.git
cd NeuralDeck
dotnet restore
dotnet run
```

## Construccion

```bash
dotnet build -c Release
```
