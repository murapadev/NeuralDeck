## ✨ Características

- ⚡ **Acceso Instantáneo**: Vive en la bandeja del sistema. Un clic y aparece
- 🌐 **Multi-AI Hub**: ChatGPT, Gemini, Claude, DeepSeek, Perplexity
- 🧠 **Chromium Engine**: Compatibilidad 1:1 con apps web modernas
- 🛡️ **Modo Stealth**: Privacidad, limpieza de cache, bloqueo de trackers
- 💻 **Cross-Platform**: Windows, macOS, Linux

## 🛠️ Instalación

```bash
# Clonar
git clone https://github.com/murapadev/NeuralDeck.git
cd NeuralDeck

# Instalar dependencias
npm install

# Ejecutar
npm run dev
```

## 🚀 Uso

```bash
# Construir para producción
npm run build

# Ejecutar en modo desarrollo
npm run dev
```
